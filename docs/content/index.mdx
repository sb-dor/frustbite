Frustbite opens an audio file or a byte buffer and tells you what is inside:
codec and stream info, tags, cover art, a waveform ready to draw, or the fully
decoded PCM. It also edits: trim, join with crossfades, mix, fade, normalize,
resample, remove silence, and save the result as WAV. The work is done by a Rust crate through FFI and Dart build hooks,
or through WebAssembly in the browser. The Dart API is pure Dart.

:::note
Frustbite supports Android, iOS, Linux, macOS, Windows and the web.
Compressed encoders (FLAC, Opus), tag writing and a CLI are on the roadmap.
:::

## Install

Add Frustbite to your `pubspec.yaml`:

```yaml
dependencies:
  frustbite: ^0.0.4
```

Native binaries ship inside the package and are picked by Dart build hooks, with no download at build time.

## Read an audio file

```dart
import 'package:frustbite/frustbite.dart';

final audio = Frustbite.fromFile('song.mp3');
try {
  print(audio.info);
  print(audio.tags.title);
  final peaks = audio.waveform(buckets: 200);
  print(peaks.channel(0).length);
} finally {
  audio.dispose();
}
```

## Edit and save

```dart
final ringtone = Frustbite.fromFile('song.mp3');
ringtone
    .edit()
    .trim(start: const Duration(seconds: 45), end: const Duration(seconds: 75))
    .fadeOut(const Duration(seconds: 2))
    .normalize()
    .saveWav('ringtone.wav');
ringtone.dispose();
```
